# Native MSVC build

Run these commands from an x64 Visual Studio Developer Command Prompt:

    cmake --preset msvc-release
    cmake --build --preset msvc-release --parallel

The build fetches pinned zlib-ng, Bifrost, and HDF5 when they are not already
installed.  BAM support remains disabled because the vendored HTSlib release
does not have a native MSVC build.
